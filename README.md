# SkillBridge LMS 🚀

SkillBridge LMS is a modern Learning Management System built using React with a professional UI, responsive design, animations, and authentication pages.

---

## 🌟 Features

* Modern Responsive UI
* Professional Hero Section
* Login & Register Pages
* Animated Components using Framer Motion
* Course Listing System
* Reusable React Components
* React Router Navigation
* Modern Dark Theme
* Mobile Friendly Design

---

## 🛠️ Tech Stack

### Frontend

* React.js
* React Router DOM
* Framer Motion
* React Icons
* CSS3

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/ThulaxanUthayakumar/SkillBridge-LMS.git
```

Go to project folder:

```bash
cd SkillBridge-LMS
```

Install dependencies:

```bash
npm install
```

Run project:

```bash
npm start
```
